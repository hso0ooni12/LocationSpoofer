# v33 – Tools Sheet

- Main map is presented as a compact rounded sheet instead of covering the entire screen.
- Replaced the long control stack below the map with a single **فتح لوحة الأدوات** entry point.
- Added a professional Tools Center sheet with unified cards and automatic dark/light mode support.
- Added schedule editor with start/end time and recurrence: one time, daily, or selected weekdays.
- Added range options for movement simulation: 100m, 500m, 1km, 5km.
- Converted the image function to a local reference-image tool only: select, preview, enable, clear.
- Expanded Bluetooth BLE scanner with captured/saved tabs, persistent log, copy UUID, share log, and clear log.
- Fixed a state reset that disabled movement every time the UI opened.
- Removed the unused AVFoundation framework from the Makefile.
